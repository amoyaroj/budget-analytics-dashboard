# 💰 Smart Budgeting Application
### Personal Finance Automation & Data Management

A Python-based financial tool designed to bridge the gap between data automation and personal financial literacy. This application automates the process of tracking expenses and managing monthly budgets through a structured data pipeline.

---

## 🚀 Project Overview
The goal of this project was to create a functional, user-centric application that simplifies expense management. It allows users to input transaction data, categorize spending, and visualize their financial health through data-driven insights.

### **Key Technical Workflow**
* **Data Input & Validation**: Implemented robust error-handling to ensure transaction amounts and dates are formatted correctly.
* **Categorization Engine**: Developed logic to automatically sort expenses into buckets like "Housing," "Groceries," and "Leisure."
* **Automation**: Integrated scripts to calculate monthly totals and variance against set budget targets.
